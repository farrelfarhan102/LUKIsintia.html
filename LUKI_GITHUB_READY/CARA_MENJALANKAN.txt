FILEPOINT - VERSI LENGKAP
===========================

1. Buka folder ini di VS Code.
2. Buat virtual environment (opsional):
   python -m venv venv
   venv\Scripts\activate       (Windows)

3. Install:
   pip install -r requirements.txt

4. Jalankan:
   python app.py

5. Buka:
   http://127.0.0.1:5000
